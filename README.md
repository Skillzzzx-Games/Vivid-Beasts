# Vivid Beasts

**Retro Gacha Tower Defense** — Collect, Evolve, Defend!

A fresh, original-IP game concept that captures the joy of Pokémon-style creature collection and strategic tower defense, all wrapped in a polished **32-bit pixel art** style.

## 🎨 Updated Art Style
- Detailed 32-bit pixel art (higher resolution, richer colors, crisper lines than classic 16-bit)
- Fully consistent sprites across title screen, collection, and gameplay
- The three starter beasts on the main menu are the exact same ones players obtain in-game

### Starter Trio (Fully Obtainable)
- **Blazeling** (Blaze • Common) — Flame fox-lizard hybrid, fire orb thrower
- **Aqualet** (Aqua • Common) — Bouncy blue water droplet, slowing jets
- **Zappup** (Bolt • Common) — Energetic lightning puppy, chain zaps

## 🚀 How to Play (Core Loop)
1. Pull beasts via generous gacha (fair pity system)
2. Level & evolve them in the collection menu (permanent evolutions with new sprites)
3. Build your team and defend pixel paths in classic TD style
4. Use type matchups, placement synergies, Signature Moves, and Trainer Skills
5. Progress through regions, rival tamers, and endless modes
